# Check if macOS Tahoe

Tahoe is macOS 26.x, released in late 2025.

## Usage

``` r
is_macos_tahoe()
```

## Value

TRUE if system is macOS Tahoe, FALSE otherwise

## Details

macOS Tahoe (version 26.x) is the successor to macOS Sequoia (version
15.x) and the predecessor of macOS Golden Gate (version 27.x). It is the
last macOS release to support Intel Macs.
