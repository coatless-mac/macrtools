# Check if macOS Golden Gate

Golden Gate is macOS 27.x, released in September 2026.

## Usage

``` r
is_macos_golden_gate()
```

## Value

TRUE if system is macOS Golden Gate, FALSE otherwise

## Details

macOS Golden Gate (version 27.x) is the successor to macOS Tahoe
(version 26.x). It is the first macOS release to run exclusively on
Apple Silicon; Tahoe was the last release to support Intel Macs.
